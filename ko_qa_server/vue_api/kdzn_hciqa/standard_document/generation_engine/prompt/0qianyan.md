## 任务要求
请根据以下的写作要求，根据提供的说明内容，生成一篇符合 GB/T 1.1—2020 的标准**前言**完整段落

## 写作规则
   - 前言为说明性内容，非规范性条款
   - 陈述有关标准起草的背景信息，不包含正文中出现的内容
   - 不得出现广告性文字
   - 使用第三人称陈述事实，语言客观、中立、简洁、正式

## 内容要点及逻辑顺序
前言的内容和顺序通常是固定的，请严格按照以下结构组织：
   1. **起草规则声明：** 固定陈述，说明本文件是按照 GB/T 1.1—2020 的规则起草的
   2. **代替情况说明 (如适用)：**
      - 明确指出本文件代替的旧版标准（包括标准号和年份）
      - 与被代替的标准相比，以列表形式清晰说明主要的**技术变化**。若无技术变化，可说明为编辑性修改
   3. **与国际标准关系 (如适用)：**
      - 说明本文件与相应国际标准（ISO/IEC等）的一致性关系（如：修改采用 MOD, 等同采用 IDT, 非等效 NEQ）
      - 若为修改采用 (MOD)，需简要说明与国际标准相比所做的**结构调整**和**技术性差异**，并说明原因
   4. **提出与归口单位：**
      - 说明本文件的提出单位
      - 说明本文件的归口单位（通常为某个全国标准化技术委员会）
   5. **起草单位与主要起草人：**
      - 列出本文件的主要起草单位
      - 列出本文件的主要起草人
   6. **历史版本发布情况：**
      - 列出本文件所代替标准的历次版本发布年份

## 内容要求
   - 章节标题固定为：`# 前言`
   - 信息必须准确、真实，与标准的实际情况完全一致
   - 各个要点之间逻辑清晰，段落分明
   - 对于“主要技术变化”等列表内容，应使用短语或简洁的句子进行概括
   - 内容仅用于陈述标准编制的背景事实，不包含任何技术要求的解释或说明

## 输出限制
   - 在生成内容时，请使用占位符（例如 `[提出单位]`、`[起草单位列表]` 等）来填充需要特地指定的信息，以便于后续替换
   - 请直接输出前言文本，不要包含任何额外的解释、开场白或结束语
