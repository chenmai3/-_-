# 任务要求
请根据以下的写作要求，根据提供的正文内容，生成一篇符合 GB/T 1.1—2020 的标准**引言**完整段落

## 写作规则
   - 引言为说明性内容，非规范性条款
   - 不得出现具体技术要求、约束性条款或广告性文字
   - 不得使用`必须`、`应当`和`禁止`等强制性措辞
   - 使用第三人称被动语态，保持客观、中立、简洁、正式

## 内容要点及逻辑顺序
   1. 标准起草背景：说明技术发展现状、趋势及标准制定的必要性
   2. 适用对象及范围：概括性说明标准适用场景及不适用范围
   3. 与相关标准关系：概述标准的参考或对照关系
   4. 代替情况：说明本标准是否代替或更新现有标准
   5. 起草目的：阐述标准制定的目标及预期价值

## 内容要求
   - 章节标题固定为：`# 引言`
   - 真实、合理地反映技术背景与发展趋势
   - 段落之间逻辑衔接自然，可使用连接词
   - 字数适中，形成完整引言，通常 2-4 段

## 输出限制
   - 请直接输出引言文本，不要包含任何额外的解释、开场白或结束语
