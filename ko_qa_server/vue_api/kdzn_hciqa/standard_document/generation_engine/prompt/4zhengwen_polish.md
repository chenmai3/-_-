## 任务要求
请对输入的正文文本进行格式规范化处理，生成符合 GB/T 1.1—2020 的标准**正文**

# 处理原则
   - 仅对以下三类内容进行结构化规范：
     - 公式
     - 表格
     - 分点列项
   - 正文内容保持自然衔接
   - 不得改变原文语义，不得扩写或删减内容，不得修改标题或章节层级

# 公式
   - 替换范围：
     - 正文自然段或自然句中内嵌的公式
     - 非规范结构的公式
   - 仅作格式调整，上下文（包含引用）应和公式内容衔接
   - 引用格式：正文中引用时，使用格式`见式（×）所示`，其中`×`指编号
   - 正文中对公式变量的说明文本需删除
   - 变量名统一使用单个英文大小写字母，并在 `</param>` 中逐一定义
   - 所有公式必须严格遵循以下示例结构：
```markdown
</formula>
    </content>$$[内容：Latex语法]$$</content>
    </label>[编号：阿拉伯数字]</label>
    </param>
        </name>$$[变量名：Latex语法]$$</name>
        </desc>[变量说明]</desc>
    </param>
    </param>
        </name>$$[变量名：Latex语法]$$</name>
        </desc>[变量说明]</desc>
    </param>
</formula>
```

# 表格
   - 替换范围：正文中出现的非规范结构表格
   - 仅作格式调整，上下文（包含引用）应和表格内容衔接
   - 引用格式：正文中引用时，应使用格式`见表（×）所示`，其中`×`指编号
   - 所有表格必须严格遵循以下示例结构：
```markdown
</table>
    </label>[表格编号：阿拉伯数字]</label>
    </desc>[表格概要描述]</desc>
    </content>[表格：markdown格式]</content>
</table>
```

# 分点列项
   - 仅对原文中已存在的分点列项（如`1.`、`（1）`、`a）`、`1）`等）进行格式优化，不得将普通段落强行改为列项
   - 仅作格式调整，上下文应和分点列项的内容保持衔接
   - 所有分点列项必须严格遵循以下示例结构：
```markdown
a) [分点1]；
b) [分点2]；
c) [分点3]。
```

   - 请忽略示例输出和示例结构中出现的 ``` 和 markdown 符号
   - 请直接输出修改后文本，不要包含任何额外的解释、开场白或结束语
