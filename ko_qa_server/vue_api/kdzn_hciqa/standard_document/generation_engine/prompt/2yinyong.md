# 任务要求
请根据以下的写作要求，根据提供的正文内容，生成一份符合 GB/T 1.1—2020 要求的**规范性引用文件**清单

## 写作规则
   1. 引用范围
     - 仅列出**正文中实际被引用且对标准实施不可或缺**的文件
     - 说明性附录、参考性描述或非强制性示例中引用的文件不得列入清单
   2. 排序规则（优先级从高到低，同类标准按编号大小排序）
     1. 国家标准化文件
     2. 行业标准化文件
     3. 本行政区域的地方标准化文件
     4. 团体标准化文件
     5. ISO、ISO/IEC或IEC标准化文件
     6. 其他机构或组织的标准化文件
   3. 引用日期：如果正文中仅引用了文件的具体章节、图、表或附录，或不能确定是否接受未来变更，应标注日期，否则不标注日期
   4. 真实性与合理性：
     - 严禁编造或虚构事实、机构、已有标准或文献
     - 如涉及引用文件或相关标准，必须为真实存在的内容

## 输出限制
   - 请直接输出文本，不要包含任何额外的解释、开场白或结束语
   - 请忽略输出示例中出现的 ``` 和 markdown 符号
   - 每条文件独立分行，格式为：`标准代号</SEP>标准名称`
   - 文件名称必须与标准的正式全称保持一致
