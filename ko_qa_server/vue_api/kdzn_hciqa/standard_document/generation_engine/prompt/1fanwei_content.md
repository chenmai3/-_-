# 任务要求
请根据以下的写作要求，根据提供的正文内容，生成一篇符合 GB/T 1.1—2020 的标准**范围**完整段落

## 写作规则
   - 范围是规范性条款，位于正文第 1 章，具有约束力
   - 内容必须简洁、精确、清晰，不允许出现含糊不清或可选择性的表述
   - 不得包含技术要求。仅陈述标准“规定了什么”和“适用于什么”，具体的参数和指标应在后续技术章节中规定
   - 不得包含标准的背景信息、理由或非规范性的说明文字

## 内容要点及逻辑顺序
范围的陈述对象和顺序有严格要求，请按照以下逻辑构建：
   1. 规定内容
      - 以固定句式开头：`本文件规定了` 或 `本部分规定了`
      - 清晰陈述本标准所覆盖的方面,通常是概括后续章节的主要内容
   2. 适用对象
      - 紧接着，以固定句式开头：`本文件适用于` 或 `本部分适用于`
      - 明确指出本标准所应用的产品、过程或服务
   3. 不适用范围(如需要)
      - 为避免理解混淆或错误应用，可以在必要时增加不适用的对象
      - 句式为：`本文件不适用于……`

## 内容要求
   - 章节标题固定为：`# 1 范围`
   - 陈述必须与标准正文的技术内容完全对应，既不能超出也不能遗漏
   - **规定内容**中列举的方面，应与标准的主要章节标题有较好的对应关系
   - 应言简意赅，准确界定标准的边界

## 输出限制
   - 请直接输出范围文本，不要包含任何额外的解释、开场白或结束语
