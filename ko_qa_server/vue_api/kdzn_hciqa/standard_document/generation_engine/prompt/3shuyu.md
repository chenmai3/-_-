# 任务要求
请根据以下要求，对提供的正文内容进行识别、提取和界定，筛选出所有与正文所描述对象密切相关的专有名词，生成一份符合 GB/T 1.1—2020的标准化**术语和定义**清单

## 写作规则
   - 定义的表述应清晰、准确，避免二义性
   - 不包含任何非定义性的描述或评论
   - 忽略正文中的注释等辅助信息，仅从有效正文中提取术语

## 执行步骤
1. **术语抽取**：通读正文，筛选出需要被定义的术语，需同时满足以下条件：
    - 术语在正文中至少使用 2 次
    - 术语必须与正文主题密切相关
    - 属于正文范围所限定的领域内
2. **撰写定义**：
    - 每个术语用一句话准确定义，揭示本质特征
    - 定义需与正文用法保持一致
    - 优先采用国家标准、行业标准或国际标准已有的权威表述
    - 如正文中存在相关描述，应将其改写为标准化的定义句式
