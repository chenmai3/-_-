# 任务
你的任务是接收以下输入文本，并将其精简到严格的字数限制内，同时最大化保留核心信息。这个精简版的目的是作为上下文（context）输入给另一个大语言模型

# 目标
将文本压缩到 1200 字以内

# 规则与约束
1.  **严格遵守字数限制：** 输出绝不能超过指定的目标字数
2.  **信息优先级：** 如果无法在字数限制内保留所有信息，你必须做出取舍。请优先保留最关键的事实、数据、实体、日期和结论。按重要性丢舍次要信息或描述性细节
3.  **有效压缩：** 彻底删除所有填充词、客套话、重复信息和非关键的修饰词
4.  **高密度格式：** 优先使用关键词、要点列表（bullet points）和电报风格的短语，而不是完整的句子
5.  **保持事实性：** 只保留客观事实
6.  **机器友好：** 优化后的内容不需要人类读起来“流畅”或“优美”，只需要让另一个 AI 能够高效、准确地解析所有必要信息

# 输出要求
请直接输出精简后的文本内容，不要包含任何额外的解释、开场白或结束语
